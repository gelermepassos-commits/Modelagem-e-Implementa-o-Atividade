# Sistema de Gestão para Clínica Veterinária com Gamificação

## Sobre o projeto
Sistema de gestão para uma clínica veterinária, desenvolvido como projeto acadêmico. 
Além das funcionalidades básicas de uma clínica (cadastro de pets, tutores, 
atendimentos, consultas etc.), o sistema conta com um diferencial de 
**gamificação**: a cada atendimento ou compra realizada, o tutor do pet 
acumula pontos e sobe de nível, podendo desbloquear conquistas e acompanhar 
um ranking.

## Objetivo geral
Oferecer uma plataforma que facilite a gestão de uma clínica veterinária 
(agendamentos, prontuários, atendimentos, produtos/serviços) enquanto 
incentiva a fidelização dos tutores por meio de um sistema de recompensas 
e engajamento (pontos, níveis e conquistas).

## Público-alvo
Clínicas veterinárias de pequeno e médio porte que desejam informatizar 
sua gestão e criar um vínculo mais próximo e recorrente com seus clientes 
(tutores de pets).

## Tecnologias
